# Flutter Labs Repository (Lab 1 - Lab 9)

Tổng hợp các bài lab thực hành Flutter từ Lab 1 đến Lab 9.

## Danh sách bài Lab

| Stt | Thư mục | Tên ứng dụng | Mô tả |
|---|---|---|---|
| 1 | [`Lab1`](./Lab1) | **I Am Rich** | Ứng dụng Flutter cơ bản hiển thị giao diện hình ảnh và màu sắc. |
| 2 | [`Lab2`](./Lab2) | **MiCard** | Ứng dụng danh thiếp cá nhân với UI hiện đại, Icon và Font custom. |
| 3 | [`Lab3`](./Lab3) | **Dice App** | Ứng dụng tung xúc xắc tương tác ngẫu nhiên. |
| 4 | [`Lab4`](./Lab4) | **Magic 8 Ball** | Ứng dụng dự đoán tương lai câu hỏi Yes/No. |
| 5 | [`Lab5`](./Lab5) | **Xylophone** | Ứng dụng đàn Xylophone phát âm thanh khi chạm các phím màu. |
| 6 | [`Lab6`](./Lab6) | **Quizzler** | Ứng dụng trắc nghiệm với ngân hàng câu hỏi và tính điểm. |
| 7 | [`Lab7`](./Lab7) | **Destini** | Ứng dụng trò chơi chọn hướng đi theo cốt truyện (Choose your own adventure). |
| 8 | [`Lab8`](./Lab8) | **BMI Calculator** | Ứng dụng tính chỉ số khối cơ thể (BMI) với UI đẹp mắt, tùy chỉnh Slider & Buttons. |
| 9 | [`Lab9`](./Lab9) | **Weather App (Clima)** | Ứng dụng thời tiết theo dõi thời tiết thời gian thực qua API & GPS. |

---

## Cách chạy dự án

1. Clone repository này về máy:
```bash
git clone <URL_REPOSITORY>
cd 9Lab
```

2. Chọn bài Lab muốn chạy (ví dụ `Lab8`):
```bash
cd Lab8
flutter pub get
flutter run
```
